# Security Lab Test Data

All data is fictional. IPs are private lab ranges (192.168.56.0/24) or documentation ranges. Nothing here targets a real system.

Layout
- sample-logs/    log files to upload to POST /api/v1/tools/logs/analyze (analyst or admin token)
- sample-data/    passwords, URLs and scan targets for the analyzers
- EXPECTED_RESULTS.md    the output each file should produce
- vulnerable-app/    descriptions of intentionally weak configurations
