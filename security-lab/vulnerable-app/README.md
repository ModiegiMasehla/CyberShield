# Safe Local Security Lab

This directory contains educational descriptions for intentionally weak configurations. They are not exposed as public attack targets by CyberShield.

Demonstrations:
1. Weak authentication — corrected by strong password policy, Argon2id and MFA.
2. Missing security headers — corrected with CSP, HSTS and related headers.
3. Insecure cookie — corrected with Secure, HttpOnly and SameSite.
4. Input validation — corrected with strict schemas and parameterized ORM operations.

Never deploy a deliberately vulnerable example to a public network.
